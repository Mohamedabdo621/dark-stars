# نجوم الظلام — DARK STARS

لعبة مغامرة فضاء HTML5 أوفلاين 100% (Canvas + JavaScript)، عربي RTL، بأسلوب داكن نيون بنفسجي.
اكتشف 9 كواكب، اجمع القطع الأثرية التسع، وافتح النجم المظلم السري.

## التشغيل

افتح `index.html` في أي متصفح حديث — لا تحتاج سيرفر ولا إنترنت إطلاقاً.
(للاختبار على الهاتف: انسخ مجلد `game/` كاملاً إلى الهاتف وافتح `index.html`.)

## التحكم

- **لمس:** عصا افتراضية يسار للتوجيه والحركة، وأزرار يمين (دفع / جمع / صعق).
- **لوحة مفاتيح:** WASD أو الأسهم للحركة والتوجيه، مسافة للصعق، E للجمع القريب، Esc للرجوع.

## طريقة اللعب باختصار

1. من الخريطة اختر كوكباً وسافر إليه (المناطق الأبعد تحتاج محركاً أقوى).
2. في الطيران: حلّق بالدفع وتجنّب الكويكبات، واقترب ببطء من الحلقة الذهبية للهبوط.
3. على السطح: اجمع البلورات والوقود، ادخل الكهف (؟) لتجد القطعة الأثرية، وتجنّب المخلوقات أو اصعقها.
4. بالبلورات اشترِ ترقيات: محرك، خزان وقود، مخزن، ماسح (يكشف الأسرار)، درع.
5. النجم المظلم يفتح بمحرك 3 + ماسح 2 + جمع القطع الأثرية الثماني الأولى.
6. الحفظ تلقائي في localStorage (حفظ/تحميل/مسح من الإعدادات).

## الملفات

- `index.html` — الواجهة (عربي RTL).
- `style.css` — النمط الداكن النيوني.
- `js/data.js` — الكواكب والترقيات والإنجازات.
- `js/logic.js` — المنطق النقي (فيزياء، توليد، اقتصاد، حفظ).
- `js/render.js` — الرسم على Canvas (كل الرسومات بالكود، لا صور).
- `js/input.js` — لوحة المفاتيح والعصا الافتراضية.
- `js/audio.js` — أصوات مولّدة بـ WebAudio (لا ملفات صوت).
- `js/game.js` — آلة الحالات وحلقة اللعب.
- `tests/` — اختبارات node.

## الاختبارات

```bash
cd game
# فحص صياغة كل ملفات JS
for f in js/*.js; do node --check "$f"; done
# اختبارات المنطق النقي (23 اختباراً)
node tests/logic.test.js
# اختبار الدخان: تشغيل الحلقة وكل الانتقالات (866 إطار)
node tests/smoke.test.js
```

## التلميع البصري

- حركة مبنية على delta-time في كل مكان (كاميرا ناعمة، اهتزاز شاشة، انتقالات fade).
- خلفية نجوم بثلاث طبقات parallax + سدم + نجوم وامضة.
- جزيئات للعادم والجمع والانفجارات والاكتشافات (بحد أقصى 240 جسيماً).
- توهج بالطبقات والألفا فقط — لا `shadowBlur` إطلاقاً (أداء 60fps).
- تدرجات الكواكب والسماء مخزّنة (لا تُبنى كل إطار)، و`devicePixelRatio` محدود بـ 2.
