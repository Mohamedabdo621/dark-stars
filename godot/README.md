# DARK STARS 3D — نجوم الظلام (Godot 4.4)

لعبة مغامرة فضاء **ثلاثية الأبعاد حقيقية** بمحرك Godot — نفس تصميم نسخة الـ 2D
(`../SPEC.md`) لكن بعالم 3D: سفينة تطير بين الكواكب، هبوط، مشي على السطح،
كهوف، مخلوقات، قطع أثرية، وترقيات. أوفلاين 100%، عربي أولاً.

## المتطلبات

- **Godot 4.4** (المحرر). حمّل من https://godotengine.org/download — نسخة
  `Godot_v4.4-stable` لنظامك.
- للتصدير إلى أندرويد من المحرر: ثبّت **قوالب التصدير** من داخل المحرر
  (Editor ← Manage Export Templates ← Download) وجهّز **Android SDK**
  (Editor ← Editor Settings ← Export ← Android ← Android Sdk Path).

## فتح المشروع

1. افتح محرر Godot.
2. اختر **Import** وحدد مجلد `godot/` (ملف `project.godot` في جذره).
3. افتح المشهد `main.tscn` واضغط **F5** (أو ▶) للتشغيل.

المشروع مكتمل بذاته: كل المشاهد والسكربتات والإعدادات داخل هذا المجلد،
ولا يعتمد على أي ملفات خارجية.

## بناء APK من المحرر

1. تأكد من تثبيت قوالب التصدير وإعداد Android SDK كما في الأعلى.
2. من القائمة: **Project ← Export…**
3. اختر الإعداد الجاهز **Android** (من ملف `export_presets.cfg`).
4. اضغط **Export Project** — سيُنشأ ملف `DARK-STARS-3D.apk` في مجلد المشروع.
   - التصدير Debug: يوقّع تلقائياً بمفتاح debug يولّده Godot.
   - الحزمة: `com.alex.darkstars`، الإصدار 1.0.0، معمارية arm64 فقط
     (هاتف أليكس 64-bit؛ لتفعيل armeabi-v7a عدّل `export_presets.cfg`).

## البناء التلقائي (GitHub Actions)

ملف `.github/workflows/build-apk-godot.yml` يبني الـ APK تلقائياً عند أي
تغيير داخل `godot/`، باستخدام صورة `barichello/godot-ci:4.4` (فيها Godot
وقوالب التصدير وAndroid SDK). الناتج: artifact باسم `dark-stars-3d-apk`.
ملاحظة: ملف الـ workflow نفسه يُضاف من واجهة GitHub على الويب (لا يمكن
دفعه عبر API)، وأول تشغيل يكون يدوياً من تبويب Actions.

## بنية المشروع

```
godot/
  project.godot        إعدادات المشروع (عمودي 720×1280، GL Compatibility)
  export_presets.cfg   إعداد تصدير Android الجاهز (debug)
  icon.svg             أيقونة اللعبة
  main.tscn            المشهد الرئيسي (يستدعي main.gd)
  scripts/
    game_data.gd       بيانات اللعبة: 9 كواكب، مناطق، ترقيات، إنجازات
    save_data.gd       الحفظ التلقائي (user://save.json)
    audio_manager.gd   أصوات مولّدة بالكود (بدون ملفات صوت)
    builders.gd        بناء كل المجسمات 3D إجرائياً (سفينة، كواكب، مخلوقات…)
    joystick.gd        عصا افتراضية للمس
    star_map.gd        خريطة النجوم 3D واختيار الكواكب
    flight.gd          الطيران: دفع، كويكبات، وقود، هبوط
    surface.gd         سطح الكوكب: مشي، جمع، كهف، مخلوقات، صعق
    main.gd            مدير اللعبة: الحالات، الواجهات، الإنجازات، اختبار الدخان
  tests/
    test_logic.gd      اختبارات منطق (بيانات/ترقيات/حفظ/فتح)
```

## طريقة اللعب

- **الخريطة:** انقر على كوكب لترى معلوماته ثم «سافر». المناطق الأبعد تحتاج
  محركاً أقوى، والنجم المظلم يحتاج محرك 3 + ماسح 2 + القطع الثماني.
- **الطيران:** العصا للتوجيه، زر «دفع» (أو مسافة) للتسارع. تجنّب الكويكبات.
  للهبوط اقترب ببطء (السرعة أقل من 14). نفاد الوقود = عودة تلقائية للوطن.
- **السطح:** تحرك بالعصا، اجمع البلورات والوقود بالاقتراب. ادخل الكهف
  للقطعة الأثرية. المخلوقات تطاردك — اصعقها بزر ⚡ (أو حرف E).
  المخلوق الذهبي النادر يهرب — اقترب منه بحذر.
- **الترقيات:** بالبلورات اشترِ محركاً وخزان وقود ومخزناً وماسحاً ودرعاً.
- **الحفظ:** تلقائي بعد كل هبوط وجمع وشراء.

## ملاحظات تقنية صادقة

- **لا توجد أي أصول ثنائية:** كل المجسمات مبنية من أشكال Godot البدائية
  (كرات، أسطوانات، صناديق) مع خامات مولّدة بالكود، والأصوات موجات PCM
  مولّدة في الذاكرة. لهذا حجم المشروع صغير ويُدفع عبر API كنص فقط.
- **الخط العربي:** الواجهة تستخدم `SystemFont` بأسماء
  (Noto Naskh Arabic, Noto Sans Arabic, …) — على أندرويد توجد هذه الخطوط
  في النظام عادةً فيعرض العربية بتشكيل صحيح (Godot يدعم التشكيل عبر
  HarfBuzz). إذا ظهرت مربعات بدل الحروف على جهاز معين، غيّر قائمة
  `font_names` في `scripts/main.gd` إلى خط عربي متوفر في ذلك الجهاز.
- **الأداء:** العرض `gl_compatibility` مناسب لأندرويد، والتضاريس والنجوم
  خفيفة (MultiMesh للنجوم، تضاريس 48×48).
- **ما لم يُختبر بعد:** التصدير الفعلي لـ APK على أندرويد (يُختبر أول مرة
  عبر GitHub Actions)، وشكل الخط العربي على جهاز حقيقي.

## الاختبارات (على الكمبيوتر)

```bash
cd godot
# الاستيراد
godot --headless --import --path .
# فحص كل السكربتات
for f in scripts/*.gd; do godot --headless --check-only --script "$f"; done
# اختبارات المنطق (34 اختباراً)
godot --headless --path . -s tests/test_logic.gd
# اختبار دخان كامل: طيران ← هبوط ← جمع بلورة ← جمع قطعة أثرية ← حفظ
godot --headless --path . res://main.tscn -- --smoke
```
